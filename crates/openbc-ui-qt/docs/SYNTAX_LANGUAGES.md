# Syntax highlighting languages and extensions

Generated from `crates/openbc-core/src/text/highlight/registry.rs`, which is the single source of truth. Do not edit this file by hand: change the table and regenerate it.

144 languages, 552 extensions and 78 well-known file names.

- **Exact** (60): a grammar written for the language.
- **Approximate** (63): the closest grammar available is used (for example TypeScript renders with the JavaScript grammar). Comments, strings and common keywords usually colour correctly; language-specific constructs may not.
- **None** (21): known language, but neither engine ships a grammar, so it renders as plain text.

Users can change any row in **Tools > Options > Syntax Highlighting**; their mappings win over this table and are saved in the profile (`preferences.ini`, group `syntaxHighlighting`).

File names (such as `Makefile`) match the whole name only. Extensions match the longest suffix first (`view.html.erb` is checked as `html.erb`, then `erb`). A leading dot is ignored (`.bashrc` is `bashrc`).
